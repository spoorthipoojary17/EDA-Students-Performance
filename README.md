# Exploratory Data Analysis – Students Performance

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a students performance dataset.

The goal is to analyze students' scores, identify patterns and trends, study relationships between subjects, and present insights using statistics and visualizations.

## Objectives

- Understand the dataset
- Check missing values and duplicate records
- Calculate statistical summaries
- Analyze student performance
- Compare average scores
- Analyze correlations
- Create visualizations
- Identify important insights

## Dataset

The dataset contains student performance information including:

- Gender
- Math Score
- Reading Score
- Writing Score

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Dataset inspection
- Missing value analysis
- Duplicate value analysis
- Statistical summary
- Score distributions
- Average score comparison
- Gender-based score comparison
- Correlation analysis
- Correlation heatmap
- Scatter plot
- Overall score calculation
- Top-performing student analysis

## Visualizations

The project includes:

- Math score distribution
- Reading score distribution
- Writing score distribution
- Average score by subject
- Average scores by gender
- Correlation heatmap
- Math score vs Reading score scatter plot

## Key Insights

- The average score for each subject was calculated.
- Score distributions were analyzed using histograms.
- Average scores were compared between subjects.
- Correlations between Math, Reading, and Writing scores were analyzed.
- An overall score was calculated for each student.
- Students were ranked based on their overall scores.

## Conclusion

This project demonstrates the basic process of Exploratory Data Analysis using Python. It includes data inspection, statistical analysis, visualization, correlation analysis, and extraction of meaningful insights.
